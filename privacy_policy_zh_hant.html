4. 帳戶刪除與資料權利

4.1 您擁有的權利

  • 存取權：查看您上傳的所有植物記錄
  • 刪除權：刪除您的帳戶及關聯資料
  • 匯出權：您的資料主要儲存於雲端資料庫（Supabase / NeonDB），您可透過 App 內帳戶管理功能存取您的雲端資料；本機 Core Data 僅作為快取層，供離線存取，您也可透過裝置備份匯出本機快取資料

4.2 帳戶刪除流程

在「帳戶管理」頁面提出刪除要求：

  1. 透過三次確認，防止誤操作
  2. 再次驗證身分（根據登入方式，可能需要密碼或 Apple ID 驗證）
  3. 資料邏輯刪除（user_id 置為 'USER_DELETED'）
  4. Supabase 使用者身分刪除
  5. 審計日誌會記錄刪除操作（用於安全審計）
  6. 本機資料清理

注意：邏輯刪除後，您的識別記錄將與使用者身分永久解除關聯（匿名化），並在後續處理週期內從伺服器實體刪除。同時，本機資料也會同步清理，確保雲端與本機資料一致刪除。

關於第三方服務使用原則：我們不會使用任何第三方服務進行使用者追蹤、廣告定向或使用者輪廓分析。所有第三方服務僅用於提供 App 的核心功能。

6. 使用者權利與權限控制

所有系統權限均為可選，您可以在首次使用時選擇允許或拒絕，也可以隨時在 iOS「設定」中更改：

本 App 提供 App 內訂閱服務，由 Apple App Store 統一處理。我們不直接收集、儲存或處理您的支付資料（如信用卡號、帳單地址等）。所有訂閱管理、付款處理及退款事宜均由 Apple 負責。

您可以在 iOS「設定」→ Apple ID →「訂閱」中查看、修改或取消您的訂閱。

8. 資料安全

  • 所有資料傳輸使用 HTTPS/TLS 加密
  • 使用者密碼透過 bcrypt 加密儲存（Supabase 處理）
  • 後端 API 使用 JWT 認證
  • 敏感操作（如刪除帳戶）需要再次驗證身分

9. 兒童隱私

本 App 並非以 13 歲以下兒童為使用對象。我們不會故意收集兒童的個人資料。
